CLIENT GUIDE / 客户端使用指南

把应用带到
你的车机。

从激活客户端到在设备上下载安装，跟随这份指南，一步一步完成操作。

开始使用 ↓
开始之前准备好电脑、激活码、要安装的应用，以及需要连接的设备。操作过程中请保持网络连接。
01 / PREPARE

先准备好
这几样东西

启动客户端并打开它提供的本机操作页面。

使用前检查

  • 一台已安装并启动客户端的 Mac 或 Windows 电脑。
  • 有效的激活码，以及可用的许可证权益。
  • 要安装的 APK 文件，或可使用的预置应用。
  • 车机与电脑的网络连接；按客户端提示开启热点并确认设备能够上网。

具体界面可能随客户端版本略有不同，请以页面提示为准。

02 / WALKTHROUGH

跟着四步完成

首次使用先激活，然后按照页面向导操作。

00

激活客户端

在客户端页面输入激活码，完成本机绑定。激活后可在页面查看授权状态和可用许可证。

请妥善保管原始激活码。换电脑前，可在“管理激活码”中解绑，再到新电脑输入原码。
01

选择应用

选择电脑中的 APK，或从可用的预置应用中选择。选择许可证，勾选本次要安装的应用，然后保存并进入下一步。

  • 选包时不会上传云端，也不会扣处理次数。
  • 切换许可证后需要重新勾选应用。
  • 文件数量和大小仍受页面、服务器及许可证限制。
02

连接并选择设备

让车机连接电脑热点，确认设备能够上网。客户端发现设备后，核对页面上的 IP 或 MAC 地址，手动选择对应设备。

系统要求网络辅助程序授权时，按提示完成授权。每轮使用都需要手动确认设备。
03

确认云端处理

在设备的应用商店刷新一次。电脑页面收到设备初始化后，核对应用和权益消耗，确认后等待处理完成。

等待期间不要反复刷新商店。若重新刷新产生新的初始化，请根据页面提示重新确认。
04

回到设备安装

当页面提示结果就绪后，回到设备应用商店，直接下载并安装所选应用。

  • 保持电脑和设备连接，直到下载完成。
  • 要更换应用或许可证时，先停止并恢复网络，再重新选择。
03 / FINISH

完成后，记得恢复网络。

在客户端页面选择“停止并恢复网络”，等待恢复完成后再断开设备。关闭浏览器页面不会自动停止客户端服务。

04 / HELP

遇到问题？

先检查连接和页面提示，再尝试以下操作。

找不到设备怎么办？

确认设备已连接电脑热点且能够上网，检查客户端所选网络接口，然后重新扫描并根据 IP 或 MAC 核对设备。

没有出现处理确认怎么办？

检查设备连接和客户端状态，在设备商店刷新一次，等待电脑页面收到初始化。避免连续刷新。

激活码如何换到另一台电脑？

先在旧电脑的“管理激活码”中解绑对应激活码，再在新电脑输入原码。已用次数和有效期不会重置；旧电脑无法使用时，请联系管理员协助处理。

云端不可用或操作失败怎么办？

根据页面错误提示检查网络及授权。需要结束时，使用“停止并恢复网络”；如果问题仍在，保存客户端提供的日志并联系支持人员。不要分享激活码或带令牌的本机页面地址。
