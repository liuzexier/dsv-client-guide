MAC / HOTSPOT SETUP

Mac 使用前：设置热点网段

仅 Mac

本教程的 Mac 热点按 192.168.50.x 网段准备。请先检查你的上网网络是否已使用 192.168.50.0/24；如果重叠，先解决网段冲突，避免影响连接。

  1. 在“系统设置 → 通用 → 共享”中关闭互联网共享，并退出系统设置。如果从未启用过互联网共享，请先完成一次热点设置，再关闭。
  2. 打开 Mac 的“终端”，先运行下面的备份命令，将现有共享配置保存到桌面。如果提示文件不存在或备份失败，请先停止并确认互联网共享已设置过。
sudo cp -p /Library/Preferences/SystemConfiguration/com.apple.nat.plist "$HOME/Desktop/com.apple.nat.$(date +%Y%m%d-%H%M%S).plist"

备份成功后，依次运行以下三行。输入 sudo 密码时屏幕不会显示字符，输入完成后按回车。

sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkNumberStart 192.168.50.0
sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkNumberEnd 192.168.50.254
sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkMask 255.255.255.0
  1. 重新打开“系统设置 → 通用 → 共享”，开启互联网共享，让车机重新连接热点。
  2. 在终端运行 ifconfig，查看热点对应的共享接口（通常名为 bridge100）。确认其 IPv4 地址属于 192.168.50.x，并在车机侧确认已获得同网段地址且可以正常上网。
没有生效？ 这组共享配置命令并非 Apple 当前支持文档中提供的设置步骤，可能因 macOS 版本或网络配置而失效；执行后必须核实实际地址。请核对共享接口的实际地址和车机网络；如仍不生效，联系支持人员协助。查看 Apple 互联网共享说明 ↗

02 ACTIVATE

启动并激活

打开客户端，将激活码绑定到当前电脑。

  1. 1
    打开客户端下载包

    Mac：解压整个目录，双击 DSV.command，或将它拖入终端后回车。不要把启动文件单独移出文件夹。

    Windows：运行与你的系统匹配的客户端程序，按程序提示完成启动。

  2. 2
    在浏览器打开本机页面

    等待客户端启动并打开页面。如果没有自动打开，使用客户端启动时显示的本机地址。保持客户端程序运行。

  3. 3
    绑定激活码

    未激活时，页面会引导你点击“绑定激活码”。输入收到的激活码并确认；成功后查看顶部授权状态。

✳保管好原始激活码

激活码绑定的是电脑上的客户端实例。更换电脑前，需要在旧电脑上解绑；绑定本身不扣处理次数。

查看换机说明 ↗
第一次看到引导？ 页面会高亮对应操作，按照提示继续即可；也可以跳过本段引导或本次启动的全部引导。
03 SELECT APPS 向导 第 1 步

选择本次应用

先选许可证，再勾选你想安装的应用。

  1. 1
    确认许可证与使用次数

    在页面顶部查看授权状态；有多个许可证时，先选择本次要使用的许可证。若页面提示“请先点击开始”，请点击右上角的“开始”。

  2. 2
    选择预置应用或本地 APK

    在“预置应用”中勾选需要的应用。允许自定义的套餐还可以在“我的应用”点击“选择 APK”，添加电脑里的文件后勾选。

  3. 3
    核对后进入下一步

    检查已选应用和剩余次数，点击“下一步：连接设备”。切换许可证会清空已勾选的应用，需要重新选择。

01 / 套餐范围

限定套餐只显示允许的套餐内应用，不能添加自定义 APK；以当前页面和许可证显示为准。

02 / 选包与扣次

选择文件本身不会上传云端或扣次；实际可选数量、文件大小和上传范围受许可证及服务器限制。

开启电脑热点

按你的系统展开
⌘使用 Mac在系统设置中开启互联网共享＋
  1. 先完成前置准备中的 Mac 热点网段设置，再打开“系统设置 → 通用 → 共享 → 互联网共享”。
  2. 按系统提示选择上网来源和共享方式，设置并开启热点。
  3. 让车机连接该热点，先确认车机原有商店可以正常上网。

系统设置名称可能因 macOS 版本而不同；具体共享选项取决于电脑的网络连接方式。

⊞使用 Windows在设置中开启移动热点＋
  1. 打开“设置 → 网络和 Internet → 移动热点”。
  2. 选择可用的上网来源并开启热点，按系统页面查看热点名称和密码。
  3. 让车机连入该热点，确认原有应用商店可以正常上网。

页面和选项可能因 Windows 版本不同而略有差异。

  1. 4
    选择共享接口并扫描

    回到客户端“连接你的车机”页面，在“共享接口”中选择车机所连热点对应的接口。等待扫描，或点击“重新扫描”。

  2. 5
    确认这是你的车机

    在设备列表里核对名称、IP 和 MAC，点击对应行的“这是我的车机”。如果系统请求管理员授权，请按提示完成；连接期间保持电脑运行。

没有找到共享接口？ 等扫描结束后检查热点是否已开启；确认系统网络共享设置，再点击“重新扫描”。
05 CONFIRM 向导 第 3 步

等待响应并确认处理

收到车机响应后，核对本次应用和权益消耗。

  1. 1
    重启车机并刷新商店

    按客户端弹窗提示，让车机断电重启并重新连接电脑热点；回到车机商店，点击连接检查或刷新应用列表。完成后可点击“我已经重新启动车机”。

  2. 2
    等待设备响应

    保持电脑客户端运行，等待页面出现“已收到设备响应，请确认本次处理”。如果响应先到，重启提示会自动关闭。

  3. 3
    阅读说明并开始处理

    核对本次应用和页面显示的次数，阅读并勾选同意说明，然后点击“开始处理”。等待应用处理及结果校验完成。

!
这一步请勿反复刷新车机商店

处理期间请保持当前设备连接。再次刷新可能产生新的设备响应，需要重新确认。成功处理后的应用即使取消安装也不退次数。

06 INSTALL 向导 第 4 步

回到车机安装

看到“处理完成，可以在设备上下载”后，就可以进行安装。

  1. 1
    确认处理已经完成

    在电脑上确认客户端已进入“在设备上完成安装”页面；阅读弹窗后点击“我知道了”。

  2. 2
    在车机商店下载并安装

    回到车机，直接点击相应应用下载，并按车机提示完成安装。此时不要再次刷新列表。

  3. 3
    等待设备完成

    下载期间保持电脑与车机连接。客户端页面会显示应用安装状态；具体安装结果以设备实际情况为准。

✓

安装完成后
客户端会尝试自动停止并恢复网络；请确认页面显示恢复完成，再断开设备。

07 AFTER YOU FINISH

结束、恢复与换机

需要更换应用或电脑时，先处理好当前会话与授权。

01

停止并恢复网络

需要提前结束或修改应用时，点击页面上的“停止”或“停止并恢复网络”，等恢复完成后再更换应用、许可证或设备。关闭浏览器页面不会停止客户端服务。

02

激活码解绑与换机

在旧电脑打开“管理激活码”，选择对应激活码解绑，再在新电脑输入原码。已用次数不恢复，到期日不重置。旧电脑无法使用时，请联系管理员核实处理。

08 NEED A HAND?

常见问题

遇到问题时，可以先从这里找找答案。

找不到共享接口，或没有发现车机怎么办？＋

先等待扫描完成。确认电脑热点已开启、车机已经连接且能正常上网；Mac 用户还应检查热点接口是否为 192.168.50.x 网段。检查页面选择的共享接口，然后点击“重新扫描”。如系统提示网络共享设置异常，先在系统设置中检查。

车机已经连接，为什么一直等待设备响应？＋

保持电脑客户端运行，按页面提示让车机断电重启、重新连入电脑热点，在车机商店点击连接检查或刷新应用列表。等待响应时不要反复刷新。

为什么无法选择本地 APK，或勾选数量受限？＋

限定套餐只能选择指定的预置应用；普通套餐才可能提供本地 APK 入口。可选应用数受许可证剩余权益等限制；切换许可证后需要重新勾选。

提示授权过期、激活失败或服务不可用怎么办？＋

先检查电脑网络、激活码和页面显示的授权状态，尝试“刷新授权”。如果问题仍在，记录页面上的提示并联系提供方；不要向他人发送完整激活码。

想换电脑，或者旧电脑无法启动怎么办？＋

旧电脑可用时，先在“管理激活码”中解绑，再在新电脑输入原码；解绑不会重置已用次数和到期日。如果旧电脑损坏或凭证丢失，请联系管理员核实。

需要反馈问题，应该提供什么？＋

在客户端“诊断与日志”中下载日志，记录出现问题的步骤和页面提示，再交给可信的支持人员。不要分享完整激活码、系统凭证或带令牌的本机页面地址。
