# DSV 客户端使用指南

DSV 客户端帮助你选择应用、连接车机，并在车机应用商店中下载安装。首次使用时，请按照下面的步骤完成准备、激活和连接。

- [图文使用指南](https://liuzexier.github.io/dsv-client-guide/)
- [下载客户端](https://github.com/liuzexier/dsv-client-guide/releases)

> 请仅处理你有权使用和处理的应用。客户端功能、可选应用和次数以你的许可证及实际页面显示为准。

## 使用前准备

- 一台能够正常上网的电脑，以及对应系统的 DSV 客户端。
- 有效的激活码。请妥善保存原码，换电脑时还需要使用。
- 一台车机，以及要安装的预置应用或套餐允许的 APK 文件。
- 电脑热点：车机需要连接电脑共享的网络，并能正常访问原有应用商店。

前往 [下载页面](https://github.com/liuzexier/dsv-client-guide/releases)，选择与你的电脑系统和处理器匹配的正式版。当前公开发布的资产为 macOS 版本；其他平台以下载页面实际提供的文件为准。

### Mac：准备热点网段

本教程的 Mac 热点按 `192.168.50.x` 网段准备。先确认电脑用于上网的网络没有使用 `192.168.50.0/24`，避免网段冲突。

1. 在“系统设置 → 通用 → 共享”中关闭“互联网共享”，然后退出系统设置。如果从未设置过互联网共享，请先完成一次设置，再关闭。
2. 打开“终端”，先备份当前配置。如果文件不存在或备份失败，请先停止操作并确认互联网共享已设置过。

   ```bash
   sudo cp -p /Library/Preferences/SystemConfiguration/com.apple.nat.plist "$HOME/Desktop/com.apple.nat.$(date +%Y%m%d-%H%M%S).plist"
   ```

3. 备份成功后，依次执行：

   ```bash
   sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkNumberStart 192.168.50.0
   sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkNumberEnd 192.168.50.254
   sudo defaults write /Library/Preferences/SystemConfiguration/com.apple.nat NAT -dict-add SharingNetworkMask 255.255.255.0
   ```

4. 重新开启互联网共享，让车机连接热点。在终端运行 `ifconfig`，确认共享接口（通常名为 `bridge100`）的 IPv4 地址属于 `192.168.50.x`；同时确认车机取得同网段地址并能上网。

输入 `sudo` 密码时屏幕不会显示字符，输入完成后按回车。这些命令不是 Apple 当前支持文档提供的设置步骤，可能因 macOS 版本或网络配置而不生效，执行后必须检查实际地址。有关共享设置，请参考 [Apple 互联网共享说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1540/mac)。

## 1. 启动并激活

1. 下载并解压适合电脑的客户端。Mac 用户保留解压后的完整目录，双击 `DSV.command` 启动；也可以将它拖入终端后按回车。不要将启动文件单独移出目录。
2. 等待浏览器打开客户端页面。如果没有自动打开，请使用启动时显示的本机地址。使用期间保持客户端运行。
3. 点击“绑定激活码”，输入收到的激活码并确认。绑定成功后，检查页面顶部的授权状态；有多个许可证时选择本次要使用的许可证。

激活本身不扣处理次数。页面上的引导可按提示操作，也可以跳过。

## 2. 选择本次应用

1. 在“预置应用”中勾选需要安装的应用。套餐允许时，也可在“我的应用”中选择电脑上的 APK 文件并勾选。
2. 核对许可证、已选应用和剩余次数，然后点击“下一步：连接设备”。

限定套餐的应用范围以页面显示为准。选择应用本身不会扣次；切换许可证后需要重新选择应用。

## 3. 连接车机

1. 开启电脑热点，让车机连接该热点，并确认车机原有应用商店可以正常上网。
2. 回到客户端，在“共享接口”中选择车机所连热点对应的接口，等待扫描或点击“重新扫描”。
3. 在设备列表中核对名称、IP 和 MAC，点击对应设备的“这是我的车机”。如果系统请求管理员授权，请按提示允许。
4. 按页面提示让车机断电重启并重新连接热点；回到车机商店，按提示进行连接检查或刷新应用列表，等待客户端收到设备响应。

如果没有发现设备，请等扫描结束后确认热点已开启、车机已连接且能上网，再检查选择的共享接口并重新扫描。

## 4. 确认处理并安装

1. 电脑页面显示“已收到设备响应，请确认本次处理”后，核对应用和次数，阅读并勾选同意说明，点击“开始处理”。
2. 保持电脑和车机连接，等待处理完成。处理成功的应用会按页面说明扣次；之后取消安装不退还已使用的次数。
3. 看到“处理完成，可以在设备上下载”后，回到车机商店，**直接点击应用下载**，并按车机提示完成安装。此时不要再次刷新列表，否则需要重新确认。
4. 安装完成后，确认客户端页面显示网络已恢复，再断开设备。需要提前结束或更换应用时，先点击“停止”或“停止并恢复网络”。关闭浏览器页面不会停止客户端服务。

## 换电脑与常见问题

**如何换电脑？** 在旧电脑的“管理激活码”中选择对应激活码并解绑，再在新电脑输入原码。解绑不会恢复已用次数或重置到期日。如果旧电脑无法使用，请联系管理员核实。

**一直等待设备响应？** 检查车机是否已按提示重启并重新连接热点，确认电脑客户端仍在运行，再按页面提示操作。处理期间不要反复刷新车机商店。

**无法选择 APK 或应用数量受限？** 可选应用、是否允许自定义 APK 和数量上限取决于许可证及服务端限制，请检查页面上的套餐和剩余次数。

**需要反馈问题？** 在客户端的“诊断与日志”中下载日志，并说明使用的电脑系统、操作步骤和页面提示。不要发送完整激活码或其他敏感信息。

更多操作说明请查看[在线图文指南](https://liuzexier.github.io/dsv-client-guide/)。
