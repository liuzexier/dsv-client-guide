# DSV 客户端使用指南

面向车机用户的静态教程网站，介绍客户端的准备、激活、选应用、连接车机、处理、安装和常见问题。当前内容参照 DSV 客户端 1.0.3 的车机模式，具体功能和文案以用户实际使用的客户端版本及许可证为准。

## 本地预览

不需要安装 Node.js、包管理器或任何前端依赖。在本目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

在浏览器打开 <http://127.0.0.1:8765/>。修改文件后刷新页面即可看到更新，按 `Ctrl+C` 停止服务器。如果 8765 端口已被占用，可改用其他端口，例如 `python3 -m http.server 8766 --bind 127.0.0.1`。

## 项目文件

- `index.html`：教程内容与语义结构。
- `style.css`：页面样式及手机、平板适配。
- `app.js`：本地准备清单计数和目录高亮；不发送数据。
- `.nojekyll`：保留给 GitHub Pages 使用。

页面可以直接由普通静态文件服务器提供，无需构建。准备清单仅保留在当前页面内，刷新后重置；页面没有账号、后台接口或数据上传功能。

## 更新内容

1. 先核对实际客户端的页面文案、许可证范围、平台支持与启动方式。
2. 在 `index.html` 修改教程，在需要时同步更新本 README 和页面样式。
3. 启动本地预览，检查桌面和手机布局、目录链接、清单计数、系统说明及常见问题。
4. 本仓库是独立教程项目；不要把客户端私有源码、凭据、激活码或内部服务配置放进公开站点。

客户端安装包由 [Release 页面](https://github.com/liuzexier/dsv-client-guide/releases)提供；可用系统和版本以该页面实际列出的资产为准。
